# guidance

Advisory engineering guidance: positions an agent weighs while interviewing, designing,
planning, building, reviewing or operating. Nothing here is binding. A review cites a
guidance file only as an advisory finding, never as a blocker; binding rules live in
[`../standards/`](../standards/README.md). A position becomes a standard by moving it there.

Each topic file holds positions only, grouped under the work stages they apply to. Read
only the files whose row matches the task. Each `File` resolves relative to this directory.
