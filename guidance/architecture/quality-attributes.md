# Quality attributes

## Interview

- When gathering requirements, walk through the full set of non-functional requirements (the -ilities), not only the functional ones.

## Design and review

- Before relying on a design, list real-world scenarios, edge cases and pitfalls, and check the design against every system it integrates with.
- Protect conceptual integrity. Apply one approach uniformly across workflows and environments, treat a shared convention as a documented public contract, and diverge per host only when needed.
