# Object-oriented design

## Design

- Prefer composition over inheritance.
- Prefer dependency injection and externalized configuration, so behavior changes through configuration rather than code edits.
- Include command-query separation (Meyer) and CQRS in the design vocabulary alongside the Gang of Four patterns.

## Design and build

- Follow SOLID (single responsibility, open-closed, Liskov substitution, interface segregation, dependency inversion), DRY with a single source of truth, and Clean Code (Robert C. Martin) as the default design principles.
