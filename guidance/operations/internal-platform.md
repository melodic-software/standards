# Internal platform

## Design

- Shape repositories, templates and tooling so the easy path is the correct one, especially for agents, which take shortcuts.
- Keep organization-wide defaults such as issue and pull request templates in one organization-level location every repository inherits.

## Design and plan

- Prefer conventions that apply to every repository in the organization over one-repository rules or maintained allowlists, and roll a shared setup out to every repository when it is tested or easily bypassed.
